# 스킬·어사이드 한국어화

원본 사도 데이터(lootandwaifus.com)는 글로벌판 "Trickcal: Chibi Go!" 기준이라, 글로벌판에도 나온 사도 **71명**의 스킬·어사이드가 영어였다.
한국 서버 전용 사도 54명은 원본에 한국어가 들어 있어 그대로 쓴다.

- 번역 파일: `data/translations_ko.json` (`tools/build_apostles.py` 가 원본 위에 덮어씀)
- **저학년/고학년 스킬 이름**: 나무위키 검색 결과에서 확인한 한국 서버 공식 이름 (142개 중 139개). `name_src: official`
- **나머지(설명, 패시브·일반 공격, 어사이드 이름 대부분)**: 임시 번역. 게임 정보 화면에 "임시 번역" 표시
- **설명의 수치·효과**: 글로벌판 원문 기준이라 한국 서버(리워크 등)와 다를 수 있음

## 확인이 필요한 항목

(2026-11 다시 확인: 이 작업 환경의 웹 검색은 한국어 위키·커뮤니티 결과를 돌려주지 않아 직접 확인하지 못함. 아는 공식 표기를 알려 주면 바로 고침. 로니 이름은 해결됨.)

그룹 '죄와 볼'에 든 사도: 죠안·알레트·시스트·멜루나·쥬비·스피키 (요미·마에스트로 2호는 그룹 밖)

| 사도 | 내용 |
|---|---|
| 죠안 | 저학년 "교리를 행하고" — 공식 이름인지 확인 못 함 (임시) |
| 요미 | 저학년 "달맞이꽃" — 확인 못 함 (임시). 고학년 "지극정성의 마중"은 공식 |
| 알레트 | 고학년 — 한국 서버 "교주의 보호 - 알레트"는 효과가 달라 "진압 준비"로 임시 번역 |
| 시스트 | 한국 서버는 "총알 배송"이 저학년·"플렉스 건"이 고학년인데 원본은 반대 (원본 순서 유지) |
| 마에스트로 2호 | 고학년 "사운더스 쇼크 웨이브" — 검색 결과 표기 그대로 (오타 가능성) |
| 멜루나 | 고학년 "멜론머스크 X" — 띄어쓰기/최신 이름 불확실 |
| 쥬비 | 고학년 "행복했쮸비" / "행복해쮸비" 중 전자 사용 |
| 스피키 | 이름은 공식이지만 한국 서버 효과가 원본 설명과 다름 |

공식 표기를 알게 되면 `data/translations_ko.json` 에서 고치고 `python3 tools/build_apostles.py` 를 실행하면 된다.
