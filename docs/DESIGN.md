# CheektoChess 기획서

트릭컬 리바이브 팬게임(비공식, 로컬 플레이용) · 오토체스 장르

> 수치는 모두 임시값이며 `data/*.json` 에서 조정한다.

## 1. 기본

| 항목 | 내용 |
|---|---|
| 엔진 | Godot 4.7 (GDScript) |
| 플랫폼 | PC(Windows/Linux) + 안드로이드, 서로 섞여서 플레이 가능 |
| 화면 | 가로 전용 (기준 해상도 1920×1080, 비율에 맞춰 늘어남) |
| 네트워크 | LAN 전용. 방장 기기가 게임 진행을 판정. 온라인은 나중에 붙일 수 있게 구조만 열어 둠 |

## 2. 대전 방식

- **인원**: 4~8명. 매 라운드 다른 플레이어와 1:1로 싸우는 생존전.
- **봇**: 방장이 대기실에서 자유롭게 추가/제거.
- **홀수 인원**: 한 명은 다른 플레이어 보드를 복제한 "유령"과 싸운다. 유령전 결과는 유령 주인에게 영향 없음.
- **짝 맞추기**: 매 라운드 무작위, 직전 상대와는 가능한 한 다시 만나지 않음.
- **연결 끊김**: 같은 라운드 안에 다시 들어오면 이어서 플레이. 다음 라운드가 시작될 때까지 돌아오지 않으면 탈락.
- **방장이 나가면** 게임이 끝난다.

## 3. 라운드 흐름

1. **준비** (30초): 수입 지급, 상점 갱신, 구매/배치/아티팩트. 모든 사람이 "준비 완료"를 누르면 바로 넘어감.
2. **전투**: 자동 전투 (최대 45초, 초과 시 무승부).
3. **결과** (3초): 패배 시 체력 감소 = 기본 2 + 라운드/3 + 상대 생존 사도 수. 무승부는 양쪽 모두 기본 피해.

## 4. 경제

| 항목 | 값 |
|---|---|
| 시작 골드 | 6 |
| 라운드 수입 | 5 + 이자(10골드당 1, 최대 5) + 연승/연패 보너스(2연속 +1, 4연속 +2, 5연속 +3) |
| 승리 보너스 | +1 |
| 새로고침 | 2골드 |
| 경험치 구매 | 4골드에 경험치 4 (라운드마다 자동 +2) |
| 레벨 | 1~9, 보드에 올릴 수 있는 사도 수 = 레벨 |
| 판매 | 코스트 × 3^(성급-1) |

상점 5칸. 사도 풀은 모든 플레이어가 공유한다(코스트별 수량 제한).

## 5. 보드

- 진영은 **전열 · 중열 · 후열** 3줄, 줄마다 3칸 (총 9칸).
- 사도는 **자기 열에만** 놓을 수 있다. **모든열** 사도는 어디든 가능.
- 대기석 8칸.
- 같은 사도 3명(같은 성급) → 자동 합성(★ +1, 최대 ★3).

## 6. 사도

- 사도마다: **열**(전열/중열/후열/모든열), **역할**(딜러/탱커/서포터), **공격 타입**(물리/마법).
- **원작 수치는 쓰지 않는다.** 역할·열·코스트·성급으로 기본 능력치를 계산한다 (`balance.json` 의 `unit_base`, `row_mult`, `cost_scale`, `star_mult`).
- 능력치: HP, 물리/마법 공격력, 물리/마법 방어력, 공격 속도, 치명타, 치명 피해, 치명타 저항, 치명 피해 저항, SP.
- **스킬** (원작 구조):
  - 저학년 스킬: SP가 가득 차면 사용.
  - 고학년 스킬: 재사용 대기시간마다 자동 사용 (첫 사용 12초, 이후 20초).
  - 일반 공격 4번째마다 강화 공격.
- **어사이드**: 1성 어사이드는 기본 적용, ★2에서 2성 어사이드, ★3에서 3성 어사이드가 추가로 열린다.

## 7. 시너지

| 분류 | 종류 |
|---|---|
| 성격 | 순수 · 냉정 · 광기 · 활발 · 우울 |
| 종족 | 수인 · 엘프 · 정령 · 요정 · 유령 · 용족 · 마녀 · 미스틱 |
| 특수 | 엘다인 (해당 사도에게만 추가로 붙음) |

- **공명**: 다섯 성격 중 하나를, **이면**(죠안): 순수/우울 중 하나를 **보드에 올릴 때마다** 고른다. 바꾸려면 대기석으로 내렸다가 다시 올린다.
- 보드 위 **서로 다른 사도** 수로 단계 발동 (기본 2/4/6, 미스틱 1/2, 엘다인 3/5/7).

## 8. 아티팩트

- 등급: **일반 → 고급 → 희귀 → 전설**. 레벨 시스템 없음 (모든 수치는 원작 Lv.1 참고).
- **획득**: 3·7·11·15 라운드 준비 단계에 무작위 3개 중 1개 선택. 각 칸은 한 번씩 따로 다시 뽑기 가능. 고르지 않으면 전투 시작 시 첫 번째가 자동 선택.
- 라운드가 뒤로 갈수록 높은 등급이 나올 확률이 오른다.
- **장착**: 사도 하나당 최대 3개. 같은 아티팩트 중복 장착 가능. **임의 해제 불가**. 판매·합성 시 보관함으로 돌아간다.
- **중복 효과**: 원작 문구를 따른다. "중첩되지 않는다"가 붙은 부가 효과는 한 사도에 1회만, 기본 능력치는 항상 중첩.
- **아티팩트 합성**: 같은 등급 2개(종류 무관, 장착 중인 것도 가능) → 다음 등급 무작위 1개(보관함으로). 전설은 합성 불가.
- **애착 효과**: 애착 사도가 장착했을 때만 적용 (Lv.1 애착 효과만, Lv.3 능력치 보너스는 없음). 이격 사도는 별개.
- 데이터: 한국 서버 89종(나무위키), 글로벌 전용 16종(lootandwaifus) — 총 105종.
