## 간이 구현 (다음 단계에서 사도별로 교체)

- **사도 스킬**: 원작 스킬 대신 역할(딜러/탱커/서포터) × 열 별 공통 스킬로 동작. 원작 스킬 이름은 표시.
- **어사이드 1성**: 설명에 나온 능력치를 +10% 하는 방식으로 자동 해석.
- **어사이드 2성**: 스킬 위력 +30% (공통).
- **어사이드 3성**: 설명의 키워드(아군 전체/같은 성격, 피해/받는 피해/공속 등)로 간이 해석.
- **애착 아티팩트 효과**: 데이터(설명)는 들어 있으나 아직 동작하지 않음 → 사도별 스킬 구현과 함께 진행.
- 원작 PvE 전용 문구는 오토체스에 맞게 바꿈:
  - 림의 낫: "일반 몬스터만" → 모든 적
  - 숭배용 액자: "웨이브 종료 시" → 적 처치 시
  - 광기의 가면: "주변의 적" → 마주 보는 적의 최전열
  - 장난감 망원경: 거리 = 양쪽 열 거리
  - 슈팡의 마법 가방: 원본 지속시간 0초 표기 → 3초

## 남은 작업

1. **첫 24명 사도 확정** (현재 `data/roster.json` 은 테스트용)
2. 사도별 원작 스킬 · 어사이드 2/3성 · 애착 효과 구현
3. 사도 스킬/어사이드 설명 한글화 (원본 데이터 일부가 영어)
4. 남은 아티팩트 아이콘 56종, 사도 모션 에셋 적용 — [ASSETS.md](ASSETS.md)
5. 실제 안드로이드 기기에서 동작·성능 확인 (클라우드 환경에서는 기기 테스트 불가)
6. 밸런스 조정

## 알려진 제한

- 안드로이드는 기기 설정에 따라 같은 와이파이 방 자동 찾기(UDP 브로드캐스트)가 안 될 수 있음 → IP 직접 입력으로 참가.
- 방장 기기가 나가면 게임이 끝남 (방장 이전 기능 없음).
- LAN에서 방장 기기로부터 업데이트를 받은 뒤에는 앱을 다시 실행해야 함 (안드로이드는 직접 다시 실행).
- 방장이 참가자보다 낮은 버전이면 참가할 수 없음 (방장이 인터넷에 연결해 업데이트하면 해결).
